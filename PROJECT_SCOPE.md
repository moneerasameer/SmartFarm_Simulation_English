# Project Scope Based on the Professor's Topic Sheet

The Smart Farm row in the supplied sheet is described as **“Applicazioni in agricoltura, protocollo Lora”** (applications in agriculture, LoRa protocol). The row has X marks under three broad areas:
1. FPGA/VHDL, microcontrollers, MATLAB and SystemC programming.
2. SystemC and MATLAB simulation.
3. Artificial intelligence, machine learning and cloud-related topics.

The sheet does not specify exact mandatory software, a required board, or detailed deliverables. This project package therefore provides software examples across MATLAB, VHDL, SystemC, Python/dashboard and a virtual LoRa model. It should not be represented as confirmed compliance with requirements that the professor has not explicitly stated.

No hardware is purchased or required for this software-only version. Physical FPGA execution and real LoRa radio communication are outside its scope.
